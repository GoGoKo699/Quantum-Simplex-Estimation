# Scientific reading route

An empirical probability vector is valid and unbiased, but its variance decreases inversely with the number of samples. Quantum mean estimation improves the precision exponent. This account asks whether the returned random vector can retain exact nonnegativity, normalization and unbiasedness at that quantum rate.

Read [the model and exact theorem](model.md), then [the probability tree](simplex-estimator.md). The tree's two ingredients are [the inherited bounded scalar clock](scalar-clock.md) and [paid exact conditional reflection](conditional-reflection.md). The proof pays for every rare conditional branch using a clock chosen from its random estimated mass.
